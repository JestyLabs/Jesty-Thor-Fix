## Research and attribution

A substantial part of this project is device investigation: physical A/B tests, Qualcomm display-stack analysis, failure injection, boot timing, wake behaviour and display-state validation.

The repository history, validation notes and research documents are intentionally public so others can verify and build on that work.

If you reuse a non-trivial investigation, result, test method or implementation from this project, please credit **Jesty Thor Fix / Jesty Labs** and link back to this repository. This attribution request does not add restrictions to GPL-licensed code; it exists to preserve clear technical provenance and make collaboration easier.
