# Jesty Thor Fix v1.7.1

- **More reliable CPU Fix**, including during app updates.
- **App Diagnostics:** tap the gear icon to view recent events and save a report.
- **Optional Sleep Trial** in Diagnostics to check how your Thor sleeps.
- **Lid Guard maintenance** for more dependable normal sleep and wake.
- **Cleaner dashboard:** clearer descriptions and improved Diagnostics, Support and GitHub buttons.

Install over your existing app to keep your settings. Changing CPU Fix manually may briefly restart the Android interface.

## Good to know

Closed-Lid Wake Guard remains **OFF by default**. Normal sleep and wake recovery was tested with the Guard enabled, but automatic blocking of an unintended closed-lid wake was not directly observed.

The updated dashboard has only text, icon and button-placement changes; the display and CPU fixes keep their existing controls.

For measurements and test details, see the [physical validation report](https://github.com/JestyLabs/Jesty-Thor-Fix/blob/main/docs/VALIDATION-EVIDENCE.md).
