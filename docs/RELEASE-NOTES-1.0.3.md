# Jesty Thor Fix 1.0.3

A small visual follow-up to the 1.0.2 dashboard refresh.

## What changed

- Support and GitHub actions are back in the top-right corner.
- The open-source message is in the bottom-right corner.
- Inside that badge, the support line now appears first, followed by the amber
  `JESTY APPS ARE FREE & OPEN SOURCE` message.

## What did not change

Display control, the CPU/DRM check, wake repair, timing, governors, frequency
limits, and the privileged bridge are unchanged.
