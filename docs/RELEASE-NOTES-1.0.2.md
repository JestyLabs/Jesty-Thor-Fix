# Jesty Thor Fix 1.0.2

This visual patch makes the dashboard cleaner and keeps the important controls
and telemetry visible on the Thor display.

## What changed

- Centered the Jesty Thor Fix lockup within the left control panel.
- Made `CPU SPEEDS` more prominent and tightened the lower telemetry panels.
- Removed the duplicated top-screen status line; that state remains available
  under **DISPLAY & SERVICE**.
- Moved the complete `JESTY APPS ARE FREE & OPEN SOURCE` message to the
  top-right in amber.
- Grouped the optional Support and GitHub actions at the bottom-right.

## What did not change

Display control, the CPU/DRM check, wake repair, timing, governors, frequency
limits, and the privileged bridge are unchanged from 1.0.1.
