# Jesty Thor Fix 0.33 pre-release

This update refreshes the public dashboard and project branding while keeping
the validated display-control strategy unchanged.

## What changed

- Approved horizontal Jesty Thor Fix lockup in the app and README.
- Consolidated CPU speeds panel for LITTLE, BIG, and PRIME clusters.
- Clearer **Bottom screen check** beside the main toggle.
- Amber/purple active-state styling and compact project/support footer.
- New maintainer-selected provisional ON/OFF dashboard artwork.
- Same package and signing certificate for an in-place update.

## Important validation status

This is a **pre-release**. The exact downloadable 0.33 APK is published before
its post-release physical-Thor checklist is complete. The established 700 ms
wake repair, 400 ms callback floor, immediate manual transitions, and final
watcher reconciliation are unchanged from the validated 0.32 line. Results for
this exact artifact will be added after testing.

## Everyday use

- No Magisk, terminal, or user-managed root setup.
- The dashboard does not need to remain open.
- Swiping the app away from Recents does not disable the fix.
- The saved ON/OFF choice survives a normal reboot.
- Android Settings -> Force stop is different and blocks automatic operation
  until the app is opened again.
